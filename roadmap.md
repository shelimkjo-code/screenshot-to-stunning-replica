# Roadmap — AI Passport & Stamp Photo Studio

- [ ] Design system (blue/white, Bangla-first fonts)
- [ ] Auth (email/password, Google, Lovable) + protected studio
- [ ] Upload + batch processing queue (per-photo + total progress, retry failed)
- [ ] Background removal: remove.bg (server) + built-in browser AI fallback
- [ ] Face enhancement: Replicate CodeFormer (server) + natural local correction
- [ ] Size presets (passport 40x50, stamp 25x35, custom), copies per photo (default 2)
- [ ] A4 layout engine in mm (300 DPI) + tests
- [ ] Live A4 preview (zoom, pages, stats)
- [ ] Downloads: PDF, PNG, individual JPEGs, ZIP, print
- [ ] Photo editor (rotate, crop/reposition, adjustments, before/after, reset, reprocess)
- [ ] Processing history + delete files / auto-delete
- [ ] Bangla (default) + English
- [ ] Blocked: remove.bg API key + Replicate connection (user must add)
